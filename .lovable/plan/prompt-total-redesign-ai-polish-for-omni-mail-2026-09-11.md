# Prompt: Total redesign + AI polish for Omni Mail

Copy the block below and send it as your next message.

---

Redesign Omni Mail so it is visually unrecognizable from the current build, and upgrade the AI experience. Keep all existing functionality, routes, and data flow exactly as they are — this is a look-and-feel plus AI-quality pass, not a rewrite.

**1. Visual identity (make it unrecognizable)**
- Rebuild the whole visual language: new type scale and pairing, new spacing rhythm, new color tokens, new corner radii, new elevation model. Nothing should read as "the same app with shadows added".
- Change the actual layout structure, not just the skin: rethink where the sidebar, list, and reader sit, how the header behaves, and how selection and focus are expressed.
- Push the blur/glass much further: layered translucency, tinted edges, depth between panes, frosted overlays on menus, sheets, dialogs, and the command palette. Blur should be a real material, not a faint backdrop.
- Keep the Material You surface toggle working — both surface modes must look intentional and distinct.

**2. Sidebar**
- Remove the big OMNI wordmark from the app sidebar entirely. Replace it with a compact, quiet identity treatment that gives the space back to navigation.

**3. AI accuracy and writing quality**
- Tighten prompts and grounding so tools operate on exactly the messages the user means — correct counts, correct date ranges, correct senders. Verify counting behavior (e.g. "star the first 10") end to end.
- Change the AI writing voice: concise, specific, human, no filler openers, no bullet-point padding, no corporate hedging. Outputs should read like a sharp assistant wrote them, not a model.
- Apply the same voice across summaries, replies, digests, and reports.

**4. Follow-up conversation on AI results**
- After any AI task finishes, show an inline box under the result where the user can ask follow-up or clarifying questions.
- Follow-ups keep the original task's context and result, and answer in the same thread of the panel. Support multiple turns.

**5. Motion and craft**
- Add considered motion everywhere: panel entrances, list stagger, hover and press feedback, reader transitions, dropdown and sheet easing, result reveal. Spring-based, fast, never bouncy or decorative for its own sake.
- Add hand-crafted CSS detail: optical alignment, subtle noise or grain, gradient edges, real hover states, thoughtful empty and loading states. It should feel designed by a person, not generated.

**6. Constraints**
- Semantic design tokens only, no hardcoded colors.
- Light and dark modes both correct across every theme preset.
- No regressions in Gmail sync, auth, sync, keyboard shortcuts, or settings.
